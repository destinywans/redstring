## 2026-09-21 应用样板修订与后续推广

用户已确认先制作 [应用列表组件样板](./application-ui-sample.md)。样板采用本地 shadcn 组合方式与 Radix/cmdk；空筛选显示“部门 / 负责人”等字段名，不提供“全部”选项，未选即不限制；搜索输入即过滤，无额外搜索按钮；多选草稿需应用。此项取代此前历史约定中的“搜索按钮提交”和“列表筛选提供全部”，当时其余页面待样板确认后迁移。随后用户回复“可以，继续推进吧”，已认可样板并授权推广，此授权明确取代此前仅限样板的实施限制；共享字体和全局环境语义保留。

## 全站视觉规则

2026-09-21 字体修订：以下字体、字号和文字颜色约定明确替代 2026-09-20 的“沿用系统字体、不另行加载字体、正文与控件均为 14px、辅助信息 12px”基线。改用自托管 MiSans 统一中西文（2026-10-19 起改回系统字体，文字角色不变），以文字角色保持一致；详细 token、字体分发与许可记录见 [全站字体与排版规范](./typography.md)。本次修订不改变搜索、筛选和环境范围语义。

| --- | --- |
| 页面一级标题 | 24px；保持清晰的标题、描述与操作区层级 |
| 字体 | 系统字体（2026-10-19 起；此前为自托管 MiSans）；代码、配置和日志使用共享等宽字体 |

## 环境与目标边界

- **列表环境只由顶部右侧全局环境控制。** 页面保留应用等业务筛选，不再提供第二套列表环境下拉。清除页面筛选不得删除 `environment_scope`。
- 列表的 `usePageScope` 默认服从全局环境。旧 URL 中的 `environment`、`environments`、`environment_filter`、`scope=all` 不能暗中覆盖当前全局列表环境；旧具体对象链接由目标选择逻辑处理。
- 受限环境没有授权匹配项时应显示空结果，不能省略过滤参数而回退到全部环境。全部应用也只表示全部已授权应用。
- **实际动作拥有明确且冻结的应用、环境目标。** 已有调查、证据、提案、审批与执行目标不随全局环境切换而改写。新操作仍需选定合法目标；当前列表范围与已有对象的目标不是同一份状态。

## 共享控件与交互

`web/src/components/filters/FilterBar.tsx` 保留 `FilterBar`、`FilterSearch`、`FilterSelect` 调用接口，旧筛选适配器统一由 `patterns/FilterPicker` 承担交互，避免继续维护两套下拉行为。表单选择使用 `web/src/components/SelectField.tsx`，与筛选器共享外观及 Radix 浮层交互；保留原生表单的 `name`、`value`、必填、禁用和 FormData 语义。嵌入原生 `<dialog>` 时，Portal 必须落在该 dialog 内，避免浏览器顶层对话框使菜单不可交互。

- 业务分类独立成页签，搜索与筛选随后排列，结果在下方展示。按真实业务提供条件，不强制所有页面拥有同一组字段。
- 本地即时筛选保留原有 `onChange` 行为；已有后端提交型查询维持关键词草稿并通过 Enter 提交。普通搜索没有额外搜索按钮，特定业务确需显式提交时通过 `showSubmit` 保留。需要 URL 状态的页面应支持刷新、后退回填；已接入页面是否完成回填以各自实现和验证为准。普通关键词控件不替代 PromQL、LogQL 等业务查询编辑器。
- 多选可搜索候选，选择暂存，点击“应用”统一提交；取消、Escape 或外部点击关闭不提交。“清空选择”先清空弹层草稿，再应用确认。
- 单选选中即提交并关闭；普通列表筛选未选显示字段名，如“部门”“负责人”，未选即不限制，不提供独立“全部”选项。必填操作表单按自身语义提供占位项，不能以“全部”作为操作目标。
- 同一筛选栏最多打开一个菜单。浮层使用 Portal、碰撞处理和高度限制；键盘支持打开、搜索、方向键选择、Enter/Space 确认、Escape 关闭与焦点返回。
- 有已应用条件标签的页面支持逐项移除；清除保留全局环境和业务分类。通常同维度 OR、不同维度 AND，特殊语义由业务明确。
- 窄屏允许换行，搜索区与菜单不得超过视口。该规范不等于本轮已完成全部窄屏与键盘验收。

## 页面落地和保留的业务差异

应用列表采用统一筛选，详情与新建使用右侧抽屉；负责人选择必须真实进入表单提交。告警页统一关键词、级别与状态。基础设施统一登记资源搜索，历史修订内容仍使用详情折叠，不当作筛选菜单替换。观测统一指标与时间选择，保留条数、起止日期及查询表达式的业务语义。

首页输入区包含发送图标、模型、上下文、`+`、`/`、`@` 入口；附件能力由 [WAN-97](https://linear.app/wansss/issue/WAN-97) 继续跟踪，本轮延期，不把入口展示等同于已可上传。CI/CD 保留导航入口与暂缓说明，本轮不启用后端交付路由。

Skills、Prompt 支持通用及应用范围，浏览通用内容不要求先选应用。编辑、组合和工具使用仍执行真实权限校验，组合进入调查时必须明确操作目标，通用模板不自动扩大应用工具权限。

人员、团队/部门、自定义时间、“更多筛选”等按页面真实能力逐步接入；没有后端语义时不虚构筛选项。本轮没有新增搜索引擎、CI/CD 执行能力或模型调用。

## 组件推广与保留边界

共享 Sheet 推广资源、基础设施、平台编辑、目录及 RBAC 的右侧卡片，浮在基础页面上，不挤占列表或画布宽度。首页可固定卡片、中央 Modal 和专用编辑器保留业务结构。共用 `PageHeader` 推广资源、基础设施与目录设置页面；数字分页与跳转遵循 [统一列表分页](./pagination.md)，不再保留样板专用每页控件槽。
