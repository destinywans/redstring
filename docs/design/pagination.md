# 统一列表分页（WAN-96）

2026-09-21 用户确认：所有完整结果列表统一位置、总条数、每页条数、当前页和左右翻页形式。沿用已确认的 MiSans、深浅主题与查询控件。

## 组件契约

使用 `web/src/components/Pagination.tsx` 与配套样式，列表底部右对齐，顺序固定：`共 N 条 · 每页 [20] 条 · 第 [P] / Q 页 · 上一页图标 / 下一页图标`。36px 控件、16px Caret 图标、14px 普通文字；窄容器右对齐换行。每页数字在箭头左侧的内容区居中。已知总页数时当前页为可输入页码，按回车或失焦直接跳转；只接受1至总页数内的安全整数，无效输入还原，Escape取消。未知总数维持只读当前页和明确的下一页能力，不宣称任意页可达。空结果为共0条、第1/1页、输入和两侧禁用。加载时控件禁用，每页选择下拉复用统一的FilterSelect。

默认每页10/20/50；应用保留5条选项。查询目标受后端并发/批量上限约束，观测只提供10/20，实时快照保留4/10/20，仍使用同一结构并标明“目标”。每页数量或筛选变化提交页码重置；数据减少导致页码失效时同步调整内容与页码。`useListPagination` 用于已取得的数组，服务端列表直接传递返回的total/page/page_size。

长期记忆和会话上下文保留旧游标API，同时支持`page=1..1000000&limit=1..50`直接读取目标页（limit默认50）。非空cursor与page互斥，不能叠加两种分页跳过记录；非法或重复page返回422，超出当前结果的页返回空items和真实total。前端单次读取所需页，输入10不会依次获取前9页。每个响应的候选集和count使用相同权限/筛选和只读一致性快照，文档投影再次核实权限；插入/删除会改变后续请求的页边界，不声称整个浏览过程锁住数据库。每次响应更新total，刷新缩减结果时读取新的最后一页。明确传入hasNext时它优先决定下一页。目标页请求失败保留当前内容与页码、显示错误，允许重试。

## 适用边界

- 应用、资源、基础设施、成员、部门、授权、记忆、告警/来源/渠道、Skills/Prompt/MCP、Runbook、连接器、自动化结果，以及“查看全部”侧卡片复用同组件。
- 只返回最近N条的接口按“本次结果共N条/已加载结果共N条”计数，并保留原查询上限说明；分页不意味着偷偷把有界读取扩为全库扫描。
- 导入预览按完整已解析名单分页，最终操作仍使用所有页，不把可见一页误当提交范围。
- 首页摘要、聊天消息、下拉候选、图表采样序列、资料属性和单项详情不是完整结果列表，不机械加入分页。暂停的CI/CD页面不改动。
