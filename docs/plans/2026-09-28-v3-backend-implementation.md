# V3 后端实施记录（2026-09-28）

用户已授权按 166 项契约分阶段改造后端，不改前端，不跑全量测试。本记录区分代码落地、契约覆盖、数据库实测和外部联通；不能把其中一个阶段当作全部完成。

## 口径与当前基线

- 字段以 `web/src/v3/api/types.ts` 为准，路由清单和语义以 `docs/api/v3-contract.md` 为准。契约含 165 条 Mock 路由及 1 条前端模拟的 SSE 路由。
- 166 项已建立[逐项接口映射](../api/v3-backend-route-matrix.md)，按旧路径适配、真实数据聚合、新增操作分类；分类仅用于排期，不是完成证明。
- V3 通过 `AIOPS_V3_INSTANCE_CONFIG` 显式启用。已绑定 V3 的数据库在漏配该配置时拒绝以旧模式启动；未迁移的旧业务路由在 V3 实例返回 `501 v3_not_implemented`，避免继续走旧角色等级与旧接口语义。保留旧数据和迁移前记录。
- 当前源码分支 `codex/v3-backend`。未修改前端。OpenAPI 生成器保留旧路由并增加已注册的 V3 路由，因此生成的操作总数不等于完成的 V3 接口数。
- Linear 第一阶段需求为 [WAN-117](https://linear.app/wansss/issue/WAN-117/v3-后端契约与环境隔离基础)，状态 In Progress；其余七阶段已在同一项目分别建项（WAN-118～124），目前仍待实施和验收。
- 当前没有可用的本地 PostgreSQL / Docker 服务，迁移和 HTTP 持久化链路尚未执行真实数据库联调。第三方服务也尚未实连；适配器的协议检查不能替代联通证明。
