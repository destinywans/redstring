# WAN-96 · 通用搜索与筛选基线

2026-09-20 用户要求先统一搜索形式、下拉、字体和排版，去掉记忆页重复的环境筛选。延续博客 Linear 视觉方向；本规范先在记忆与上下文页落地，其他页面等待反馈后迁移。相关 [WAN-96](https://linear.app/wansss/issue/WAN-96)、WAN-88、WAN-94、WAN-95。

## 结构与边界

- 左上角环境定义列表的全局读取范围，记忆页不再提供环境下拉；清除页面筛选不重置全局环境。旧记忆URL的 environment/environments/environment_filter/scope 覆盖参数在本页移除，查询遵循可见的 environment_scope。其他页面旧链接和具体操作目标本轮不改变。
- 业务分类独立成页签行，搜索和筛选在下一行；条件标签位于其下，内容结果接续展示。不要把页签、页面范围、关键词、状态混在同一行争夺宽度。
- 常用条件直接展示；条件多时将低频项收进“更多筛选”，应用后仍展示对应标签。首个落地页没有足够的受支持条件，不显示空的“更多筛选”。
- 应用、人员、部门/团队、时间共用控件规范，各页面按语义选取。通用组件不意味着所有页都塞相同字段。

桌面示意：

```text
长期知识与经验     会话上下文
─────────────────────────────────────────────────────────
[ 搜索标题、内容或来源          ][搜索] [应用 · 全部 ▾] [类型 ▾] [状态 ▾]
[应用：Checkout ×] [状态：已发布 ×]  清除筛选              已加载 N 条
─────────────────────────────────────────────────────────
列表 / 详情
```

## 视觉规范

复用现有字体栈，不加载新的字体。控件文字14px、辅助文字12px；控件高36px、左右内边距12px、圆角8px、间距8px。页面一级标题继续现有层级。应用名称左对齐，触发按钮保留清晰的字段名、当前值和右侧箭头；长文本截断并可查完整名称，不靠贴边缩字解决密度。

浅色复用 `--bg #f7f8fa`、`--panel #ffffff`、`--border #dce1e8`、`--text #202734`、`--muted #626d7f`、紫色 `--accent #6552cb`；深色用现有对应token。弹层使用确定的 panel 背景，不能引用未定义的surface导致文本透叠。选中、悬停和键盘焦点均有反馈，不只依靠字体颜色。主题过渡沿用平台规范，减少动效时关闭弹层位移动画。

## 交互契约

- 关键词：输入保持草稿，Enter或搜索按钮提交；页面后退/刷新回填已提交关键词。当前上限200字符，字段匹配语义由后端决定，不暗示支持未实现的高级语法。
- 应用/人员等多选：可在下拉内部搜索候选，选择暂存；“应用”一次提交，取消/点击外部/Escape关闭不提交。清空选择先更新弹层草稿，需要应用确认；空数组表示全部授权范围，不是全部平台资源。
- 类型/状态单选：选中立即生效并关闭，提供全部选项。业务状态取真实状态机，不强行把每个领域映射成同一组状态。
- 每个筛选栏最多打开一个面板；浮层通过Portal渲染并处理碰撞/可用高度，避免两个原生details同时展开与父容器裁剪。
- 已应用条件展示标签，可单独移除；清除筛选保留全局环境和当前业务页签。选项间OR、不同维度间AND；特殊业务语义需明确说明。
- 键盘可打开、搜索、方向键选择、Enter/Space确认、Escape关闭并归还焦点。窄屏允许筛选栏换行，搜索占整行，弹层不超出视口。

## 通用维度建议（尚未全部实现）

| 维度 | 控件形式 | 语义要求 |
| --- | --- | --- |
| 应用 | 可搜索多选 | 只列已授权应用；应用ID存URL，名称只负责显示 |
| 人员 | 可搜索人员选择 | 明确负责人、创建人或处理人，不能混成含义模糊的“人员”过滤 |
| 部门/团队 | 搜索选择；有真实树结构时才提供树 | 当前项目主要为团队，不虚构企业部门层级；“包含下级”必须有后端语义 |
| 时间 | 常用区间＋自定义起止 | 明确创建/更新/发生时间和时区；相对时间保留相对含义，绝对时间标准化入URL |
| 类型/状态 | 同一选择器外观 | 候选值由业务提供；无法支持的组合不展示或明确禁用 |

本轮只实现记忆现有API支持的关键词、应用、类型、生命周期。人员/部门/时间、“更多筛选”和跨页面批量替换仍是设计方向。没有增加搜索引擎、后端字段、人员授权或索引流程。

## 实现位置和验收

组件：web/src/components/filters/FilterBar.tsx / filters.css；首个使用处 MemoryPage。usePageScope 的 globalEnvironmentOnly 是显式选择，默认保持其他调用方兼容。

只做受影响前端构建与记忆页定向浏览器检查（下拉互斥、筛选/取消/清除、URL刷新、全局环境、深浅、390px、键盘）；不运行全量测试、真实模型或发布实验。交付与检查点随实际结果更新，用户未确认前为 In Review。
