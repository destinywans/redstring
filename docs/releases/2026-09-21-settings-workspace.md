# WAN-103 · 独立设置工作区

## 用户确认与取舍

用户要求用户名位于左下角，向上弹出设置、帮助与支持、退出登录；设置采用独立页面或全页覆盖卡片，统一容纳平台概览、成员、部门 / 团队、角色与资源范围。选择独立页面，提供返回工作台，设置的内容密度和后续扩展不再受业务侧栏与右侧面板限制。

内容参考 `docs/design/platform-2026-09-21/images/settings-{overview,members,teams,roles}.png`。本轮最新说明覆盖图中“下方弹出的用户菜单”和业务侧栏内页签。编辑仍使用悬浮覆盖卡片，不挤压底层页面。图中版本、人员和权限符号不是服务端事实；operator 的审批能力保持既有确认，不照图改权限。

## 实施

- 用户菜单增加可用的帮助与支持，保留退出登录；设置四页使用统一左侧导航、返回工作台和主题切换。平台目录无环境筛选。
- 概览读取平台资料和当前配置计数，名称、简介、时区可保存，使用 revision 防止过期覆盖。配置数量不当作健康状态。
- 成员：搜索、角色/团队/状态筛选、分页、详情、新建/编辑/停用/删除、复用目录导入。示例成员禁止登录；旧记录无可证日期显示未知。
- 团队：部门目录、搜索筛选、团队资料、负责人、成员维护和应用归属 / 授权。负责人必须为当前团队成员。部门是资料字段聚合，未扩展组织树。
- 权限：真实固定角色矩阵、应用 grants 的查看、新增、编辑和移除；不提供未实现的动态角色或服务 / namespace 级授权。
- PostgreSQL 012 迁移和显式种子：8 位禁用示例成员、3 个示例团队、3 个部门，复用现有应用生成首次示例只读授权；现有真实账号、密码、业务归属不改。重跑不补回或扩大授权。

契约见 [settings-api.md](../settings-api.md)。平台角色能力为既有真实模型，Mock 用于人员与团队资料，不能提升登录权限。

## 验证与当前状态

- 前端受影响构建通过；独立 clean snapshot 后端编译通过，排除暂停中的 delivery/deployment 工作线。
- 设置模块定向测试及随机隔离 PG schema 检查通过：鉴权 401/403、乐观锁 409、字段和时区校验 422、Mock 禁登录、最后真实管理员保护、删除 / 退出负责人的显示、事务审计、首次初始化与种子重跑。
- 隔离契约 110 个操作匹配；完整工作区的暂停模块留在未提交改动中，不混入本次提交。
- 本机 18081 已应用 012 并载入数据库示例资料。浏览器检查用户菜单、独立导航、四页数据、筛选 / 浮卡、平台资料刷新保留和成员 / 团队保存；在示例成员上新增只读授权、检索并移除，确认未留下测试授权。帮助弹窗 Escape 关闭返回触发焦点，设置可返回工作台。四图与实际内容并置、1113px / 1280px 桌面布局和深浅主题已查看。更多视觉记录见仓库 `design-qa.md`。
