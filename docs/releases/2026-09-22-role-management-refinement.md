# WAN-105 · 角色管理体验与关联修订

用户反馈：未保存提示横幅干扰编辑，描述可无限拖高，角色列表展示内部编号、图标、来源和重复操作；预置角色关联只读不符合实际管理需要。2026-09-22 明确实施；分支 `codex/wan-105-role-management-refinement` 依赖已推送未合并的全站组件基线 `7e28d55`。

## 产品行为

- 点击卡片关闭、空白遮罩或 Escape 时，有修改则使用共享居中确认。继续编辑保留草稿；放弃后才关闭。角色/权限资料卡与宽幅关联均复用此行为。
- 描述最多 2000 字符并显示计数。输入框固定 120px，内容超出后内部滚动，取消拖动手柄；列表描述单行省略，完整内容在详情查看。
- 角色名称保持数据库唯一约束；创建或重命名重名返回明确中文提示。隐藏角色内部 ID、来源、行图标和操作列，表头为角色名称、权限、用户、部门。点击名称打开资料卡，再进入管理关联。稳定数据库 ID 仅供内部引用，改名不破坏关联。
- 预置角色和自定义角色均可管理权限、用户、部门关联；不再因 builtin 整体只读。预置基本定义的编辑/删除以及权限条目特殊兼容范围不在此次放开范围。
- 由成员管理同步的账户基础角色关联按单行锁定并说明调整入口；其他用户、部门和权限仍可编辑。不在取消勾选时自动改变账户基础身份。
- 管理权限需要在关联写入事务中重检，既有版本冲突和原子提交保留；防止移除最后实际具有角色权限管理能力的启用账户。预置 viewer 可以被配置额外权限，因此成员写入不能再假设它永远无特权。
