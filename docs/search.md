# 文本搜索约定

- 支持中文原文、英文（不区分大小写）、中文全拼和首字母。例如“资源查看”可输入 `ziyuanchakan`、`zyck`、`资源chakan`。原文匹配优先，输入纯中文时保持字面匹配，不按首字母扩大结果。
- 拼音匹配忽略空白，`ü` 记作 `v`；混合查询中用户输入的中文字保留字面约束。百分号、下划线及其他符号是普通文本，不是SQL通配符。
- 前端、Go 和 PostgreSQL 使用 `shared/search/pinyin.json` 同一份 go-pinyin 成熟字典，生成工具和 MIT 许可随库保存。采用字典默认单字读音，不提供多音词上下文推断、拼写纠错或任意混合全拼/首字母组合。
- 前端本地列表、共享下拉及工作区检索调用 `web/src/lib/search.ts`；资源目录内存过滤调用 `internal/searchtext`；PG 分页检索调用 `aiops_search_match`，权限、计数、分页范围保持原有语义，不只搜索当前页。
- 覆盖角色/权限和资源树、部门、资源目录、应用和基础设施列表、成员、Skills/Prompt、告警、知识、记忆、审计、调查证据、已返回日志的文字查找及共享选择器。审计分页形式不改。
- PromQL、LogQL 等原生遥测查询及结构化资源标识输入保持原义；不会把拼音自动改写为执行语句。
- SQL 字典在019迁移安装；此实现优先服务当前规模，未做大数据压力验证。部署与定向检查结果以本轮交付记录为准。
