# AIOps 全站设计图评审

需求：[WAN-100](https://linear.app/wansss/issue/WAN-100)。前置资源菜单：[WAN-99](https://linear.app/wansss/issue/WAN-99)。状态：设计评审，不是功能验收。

打开 [图库](index.html)，按左侧菜单分类或关键词查找，点击缩略图查看原图，使用上一张/下一张或方向键切换。全部文件可离线打开；图库只展示图片，没有产品操作或数据请求。当前本机入口为 `http://127.0.0.1:18081/design-review/gallery.html`，下次前端重建会清除该临时副本，仓库内图稿与下载归档保留。

35个子菜单，加工作台、交付中心暂停入口、审计日志，共38张独立图片。不是38种风格供择一：它们共同覆盖当前平台，统一视觉方向、不同业务结构。深色主题、窄视口、动效、所有表单及空/错/载入状态不在这38张桌面概念图覆盖范围。

- [设计简报](brief.md)：已确认方向、功能边界与统一视觉目标。
- [完整目录](manifest.json)：页面名、分组、路由及功能构图说明。
- [评审备注](review-notes.md)：图像语义与实现约束；逐组详细记录在同目录 `*-review.md`。
- `images/`：38张最终 PNG；保留工具原始分辨率，不程序性修图。
- `prompts/`：原始与修订提示词；标有 `-revision` / `-final` 的说明后一次变更。
- `index.html`、`gallery.css`、`gallery.js`：静态图库，无外部依赖；JS内嵌目录以支持本地打开。

生成图中的额外选项、示例平台、术语和数值不会自动成为需求；CI/CD继续暂停。后续先按用户反馈修设计，再以已确认页面拆分实施。已有代码仅增加两个明确待接入资源页，没有批量重做整个 SaaS。
