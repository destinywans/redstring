# 共用卡片关闭按钮

- WAN-96，用户明确要求关闭叉号默认可辨识，悬浮具有不同样式。
- Sheet / Modal 复用关闭样式：默认轻背景、清晰边框与正文色叉号；悬浮强调背景/边框/图标，按下即时反馈；保留键盘焦点、禁用及减少动态效果设置。
- 沿用现有尺寸、位置、图标与深浅色主题变量，不修改关闭行为或未保存保护。
- 本次与 WAN-105 的资源关联及默认记录管理同批更新本机 18081，源码独立提交。仅受影响前端构建及代表性卡片检查，未运行全站测试。

## 用户再次反馈后的修订

- 旧默认/悬浮对比仍不够；共享按钮统一 36px，叉号20px及2.5px描边，默认加强底色与边框，悬浮实色强调，按下立即加深、内阴影与轻微下压。减少动态效果时取消位移。
- 只调整共享样式；深浅色依赖现有主题变量，关闭逻辑未改。类型与构建通过，本机18081已更新，浏览器只查看权限创建卡片并关闭；未做全站检查，悬浮/按下新效果待用户体验。
