## 组件契约

2026-09-21 样板验收后追加修订：用户认可样板并授权继续推广，以下数字分页替代此前“每页 [20] 条 / 第 [P] / Q 页”的排列与数字独立框形式。

使用 `web/src/components/Pagination.tsx` 与配套样式，列表底部右对齐，顺序固定：

`共 N 条  ‹  1 2 3 4 5 … 10  ›  [10 条/页 ▾]  前往 [P] 页`

- 已知精确总数时展示数字页码。首尾页始终可见，当前页使用 `aria-current="page"` 和选中状态；前部展示前五页，尾部展示后五页，中部保留当前页及相邻页。少量页数直接完整显示，省略号为不可点击文本，不伪装成跳转按钮。
- 上一页和下一页箭头分别位于数字页码两侧；第一页禁用上一页，最后一页禁用下一页。
- 每页选择使用共享 `ui/Select`，完整的“10 条/页”放在同一方框内，不把单位拆到框外；选择必填，没有清空项。移除样板专用 `pageSizeControl` 插槽，所有调用方统一使用共享控件。
- “前往 [P] 页”支持 Enter 或失焦跳转；只接受 1 至总页数内的安全整数，无效输入还原，Escape 取消。加载时分页控件禁用。
- 未知精确总数的游标列表保留真实当前页及明确的前后翻页能力；可展示调用方提供的已加载条数说明，不虚构全库总数、数字页码或任意页跳转。
- 空结果显示共 0 条及第 1 页，翻页与跳页禁用。控件使用 34px 高度、16px 箭头、14px 常规文字；窄容器右对齐换行。
- 交互反馈独立于主题切换：页码悬停只显示浅底色、不加阴影，底色和文字过渡为 80ms；当前页底色、边框与跳页输入焦点立即变化。不能继承全局主题的 850ms 慢过渡；键盘焦点和减少动效规则保留。

默认每页10/20/50；应用保留5条选项。查询目标受后端并发/批量上限约束，观测只提供10/20，实时快照保留4/10/20，仍使用同一结构并标明“目标”。每页数量或筛选变化提交页码重置；数据减少导致页码失效时同步调整内容与页码。`useListPagination` 用于已取得的数组，服务端列表直接传递返回的total/page/page_size。

长期记忆和会话上下文保留旧游标API，同时支持`page=1..1000000&limit=1..50`直接读取目标页（limit默认50）。非空cursor与page互斥，不能叠加两种分页跳过记录；非法或重复page返回422，超出当前结果的页返回空items和真实total。前端单次读取所需页，输入10不会依次获取前9页。每个响应的候选集和count使用相同权限/筛选和只读一致性快照，文档投影再次核实权限；插入/删除会改变后续请求的页边界，不声称整个浏览过程锁住数据库。每次响应更新total，刷新缩减结果时读取新的最后一页。明确传入 hasNext 时使用服务端的下一页能力；若同时已知精确总页数，到达最后一页仍禁止越界。目标页请求失败保留当前内容与页码、显示错误，允许重试。

## 适用边界

- 应用、资源、基础设施、成员、部门、授权、记忆、告警/来源/渠道、Skills/Prompt/MCP、Runbook、连接器、自动化结果，以及“查看全部”侧卡片复用同组件。
- 只返回最近N条的接口按“本次结果共N条/已加载结果共N条”计数，并保留原查询上限说明；分页不意味着偷偷把有界读取扩为全库扫描。
- 导入预览按完整已解析名单分页，最终操作仍使用所有页，不把可见一页误当提交范围。
- 首页摘要、聊天消息、下拉候选、图表采样序列、资料属性和单项详情不是完整结果列表，不机械加入分页。暂停的CI/CD页面不改动。
