# Redstring 品牌

产品名只用英文 **Redstring**，中英文界面相同，不设中文名。2026-10-09 起替换原名 AIOps Canvas；Go 模块、`cmd/aiops`、接口路径、请求头和本地存储键（`aiops-*`）不改。

## 标志

一道红色闪电（折线）穿过两条线索，落在红色的根因点上：告警像闪电一样落下，红线把线索串起来，直达根因。

- 64 × 64 网格。两笔斜线互相平行，都是 45°，长度相同；中间的折返向上约 14°，两个转角约 31°，保留尖角。
- 两个线索点在上下两笔的中点，用墨色；根因点在终点，比线索点大约 15%，是唯一的红色实心点。
- 线在每个点前断开 1.4，读起来是“穿过”点。
- 安全留白：四周至少一个根因点直径。最小 16 px。

| 显示尺寸 | 线宽 | 点与线之间 | 线索点 / 根因点半径 |
| --- | --- | --- | --- |
| 48 px 及以上 | 3.6 | 断开 1.4 | 3.8 / 4.4 |
| 25–47 px | 4.2 | 断开 1.4 | 3.8 / 4.4 |
| 24 px 及以下 | 5.2 | 不断开 | 4.6 / 5.3 |

## 颜色

| | 浅色背景 | 深色背景 |
| --- | --- | --- |
| 品牌红（线、根因点） | `#E5484D` | `#F2555A` |
| 墨色（线索点） | `#111113` | `#F2F2F3` |

品牌红只用在标志上。界面主色仍是靛蓝 `#5B5BD6`：运维界面里红色表示错误和严重告警，不用作按钮或选中态。前端通过 `--brand-red`、`--brand-ink` 两个变量取色。

## 动效

`web/src/v3/ui/BrandMark.tsx` 提供四种状态：

- `static`：静态标志。
- `intro`：0.46 秒画线，点依次弹出，结束时闪两下。只在应用启动时由侧栏播放一次。
- `loading`：线变淡，一道电流沿线跑，每圈 1 秒。用于启动占位（`web/index.html`）。
- `thinking`：三个点依次亮起，1.5 秒一轮。用于 AI 正在生成或分析的位置。

系统开启“减少动态效果”时全部显示静态标志。

## 文件

由 `scripts/brand-assets.py` 生成（PNG 需要 macOS 和 Swift），几何与 `BrandMark.tsx` 一致，修改时两处同步：

- `web/public/`：`favicon.svg`（随系统深浅色切换）、`favicon-32.png`、`apple-touch-icon.png`。
- `docs/brand/`：`redstring-mark.svg`（浅底）、`redstring-mark-on-dark.svg`（深底）、`redstring-mark-mono.svg`（单色，跟随 `currentColor`）、`redstring-app-icon.svg` 与 512 px PNG。
