# V3 Prometheus Pull 领域接入

服务端来源配置示例见 [v3-pull-sources.json](v3-pull-sources.json)。每个 Pull ID 固定到一个已持久化的应用、环境、Prometheus 连接器、`metric_resource` 目标及经操作员审核的查询 ID/表达式。来源 ID 的应用、环境、连接器、目标、资源、查询 ID，以及表达式和标签白名单的摘要会持久登记；修改任一绑定或查询策略须分配新 ID，旧 ID 重绑返回 `source_identity_changed`，避免历史预算与审计身份混淆。查询必须在 Prometheus 数据层约束该应用和环境；仅凭配置键相等无法证明任意 PromQL 的数据范围。生产配置文件保持私有，不将真实地址、凭据、表达式或采集数据写入仓库。来源 ID 由服务端选择，请求不能覆盖 URL、PromQL、Vault 引用或目标。

本批仅支持已登记的 Prometheus 指标目标。其他供应商和任意 JSON API 尚无对应的受审查目标登记及查询边界，不按前端通用 HTTP 编辑器执行。`GET /api/v1/ingest/pull/{id}` 和 `POST /api/v1/ingest/pull/{id}/test` 均在一个明确选定的 V3 环境中执行实时有界读取；`all` 环境仅供汇总浏览，执行返回 `env_view_only`。GET 要求 `connectors.view`，POST 同时要求 `connectors.view` 和 `connectors.manage`，两者还须对目标应用或其当前所属团队有 `services.view`。两路在上游读取后重新核对原 Cookie 会话、来源和授权，撤权时不返回样例。撤权恰在前置核对与 HTTP 读取之间提交时，可能仍发出一次有界只读上游请求；最终核对阻止向调用方返回该样例。

读取使用已登记连接器的真实端点和服务端审核的 `query_range` 表达式。带凭据连接器仅在层级、环境、连接器 ID、供应商、端点和 Vault 引用精确匹配部署方绑定时取出令牌。响应中只显示请求模板的非秘密部分；`sample.body` 是本次查询转换后的最多五行**规范化样例**，不是原始上游正文，`preview.rows` 最多二十行。预览和测试计数必须来自真实返回；本机/受控夹具验证不证明生产连接已通。

`POST /test` 请求体必须是 JSON 对象：`{}`，或包含同时给出 `name_label` 与 `label_keys` 数组的预先批准标签选择。`mapping: null` 和缺字段均返回 422。例如：

```json
{
  "mapping": {
    "name_label": "__name__",
    "label_keys": ["pod"]
  }
}
```

服务名称固定来自应用绑定，时间从经验证的 Unix 秒转换为 RFC 3339，值按有限浮点样本转换；缺少所选名称标签的点计入 `dropped`。成功返回实际转换后的 `{ "ok": true, "rows": 1, "dropped": 0, "captured_at": "..." }`；这里的数值仅示意响应形状，不是固定成功结果。任意 JSONPath、脚本、分页参数及不在名单的标签会被拒绝。

Prometheus `query_range` 没有游标分页，因此 `request.paging` 明确为无分页。单次读取限定固定五分钟窗口、三十秒步长、五秒 HTTP 超时及四 MiB 正文；协议自身限制系列和样本数，并对触顶、警告、部分或过大响应报错，不把截断结果当作完整预览。两路共用数据库中的每个来源与操作者组合预算（10 次/分钟）、来源总预算（60 次/分钟）及同时在途上限，超额返回 429 和 `Retry-After: 60`。只持久记录净化后的尝试摘要、预算和管理审计；不保存 Vault 令牌、原始上游正文或样本内容。最终授权失败另写失败审计；数据库整体不可用时返回 503 且不返回样例，但已预留的尝试可能暂留 `pending`，需运维核查。当前没有已批准的尝试记录清理期，数据库表会随调用增长；上线前需确认留存和容量预算。

未登记或跨环境来源返回 404，无权返回 403，停用/变更的目标、重绑来源 ID 或 `all` 环境返回 409，映射或请求体无效返回 422，限流返回 429，上游失败/不完整返回 502，精确凭据绑定或审计不可用返回 503。恢复时核对已登记目标、连接器启用与 `query_metrics` 开关、审核查询数据范围、精确 Vault 绑定及当前授权。冻结前端目前仍只获取固定 Mock Pull ID，保存/测试按钮不发真实 POST；WAN-117 还需接入本领域模块及分域 OpenAPI，才能对 V3 主接口做进程级验收。
