## 字体与覆盖范围

界面通过 `--font-ui` 使用系统字体：拉丁字母和数字先用系统界面字体（macOS 的 SF Pro、Windows 的 Segoe UI），中文依次回退到苹方、冬青黑体、微软雅黑、Noto Sans CJK SC。不下载字体，各系统看到的字形会有差别。规范覆盖页面、导航、表格、表单、抽屉、Portal 弹层、独立设置页、图表及调查画布。

统一以文字角色为单位，不要求所有文字同尺寸。相同角色共享字号、字重和行高；标题、正文、操作控件与辅助信息保持清晰层级。避免为某一页面另起字号体系，也不通过缩小文字容纳长名称；长内容优先换行，必要时截断并保留完整内容入口。

代码、配置和日志使用 `--font-mono`，字号为 14px，中文回退到系统中文字体。普通业务名称、资源名称与标识按界面文字处理；确需表达命令或配置语法时使用等宽字体。

## 字号与字重

| 文字角色 | Token | 字号 |
| --- | --- | --- |
| 正文、主要说明 | `--type-body` | 15px |
| 控件、导航、紧凑列表文字 | `--type-small` | 14px |
| 时间、状态补充、元数据 | `--type-caption` / `--type-meta` | 13px，作为常规 UI 最小字号 |
| 小标题 | `--type-section` | 18px |
| 首页主要输入 | `--type-lead` | 18px |
| 页面标题 | `--type-page` | 24px |
| 关键数值 | `--type-metric` | 28px |
| 首页大标题 | `--type-hero` | 36px；视口不超过 760px 时为 28px |

正文、资料值、普通导航、表单标签及输入/下拉内容使用 `--weight-regular: 400`；操作按钮、选中导航、表头及明确的行内强调使用 `--weight-medium: 500`；页面、分区和卡片标题使用 `--weight-semibold: 600`。不能因使用 label、button、strong 标签而让普通内容继承标题字重。汇总数字最多使用 500；普通列表名称和元数据不额外加粗。

同轮反馈中，用户认可 MiSans 字形但认为初版 450 普通字重与大量 500/600 控件偏重。此处采用 400 替代该中间方案（2026-10-19 改用系统字体后沿用这组字重）；通过字号和颜色保留阅读层级，而非对所有内容加粗。

正文行高为 `--leading-body: 1.65`，控件为 `--leading-ui: 1.45`，标题为 `--leading-heading: 1.35`。普通文字字距为 `0`，标题最多采用轻微收紧的 `-0.02em`，避免中文排版过密。增大字号时同时检查容器高度、换行与截断，不把代码修改或构建通过当作视觉验收。

| --- | --- | --- |
| 浅色 | `#242d3c` | `#596579` |
| 深色 | `#ebedf3` | `#adb5c4` |

## 字体分发与许可记录

2026-10-19 起应用不再分发字体文件，也不从第三方 CDN 加载字体。在此之前，应用保存 MiSans 官方完整可变字体的 WOFF2（`web/src/assets/fonts/MiSansVF.woff2`，11,931,324 字节）和许可 PDF，帮助弹窗显示字体署名与许可入口；这些文件已从当前版本删除，但仍在 v0.1.0 之前的 git 历史里，受《MiSans 字体知识产权许可协议》约束，见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。

改用系统字体的取舍（14px 实测，Chromium、macOS）：中文是等宽方块，20 个汉字的宽度 MiSans 292px、苹方 291px、Noto Sans SC 289px，版面不重排；拉丁字母在 600 字重下比 MiSans 窄约 4%（同一串文字 319px 对 306px），x 高度（小写字母高度占字号的比例）从 54% 降到 51%，标题和服务名看起来轻一点。Noto Sans SC 把中点“·”排成全角，前后空隙变大。首次加载不再下载约 11.4 MiB 的字体。Windows 微软雅黑没有实测。
