# v3 前端演示就绪（2026-10-07）

用户要求：后端仍在开发、没有真实数据时，前端要能完整演示，所有按钮点了都要有反应。只改前端，不改 API 契约。

## 排查方法

- 静态扫描 `web/src/v3`，找出没有绑定动作的控件：`Btn`、`button`、`IconBtn`、`Chip`、`TextLink`、`a`，以及没有 `onSelect` 的菜单项。共 153 处。
- 检查空处理函数和只弹提示、实际不做事的动作。共发现以下几类：
  - 「撤销」是空函数；
  - 「导出」只弹提示、不下载文件；
  - 外部链接打开虚构地址 `*.example.internal`；
  - 标签页切换后内容不变。
- 核对链接目标：所有站内跳转都有对应路由。

## 新增通用组件（`web/src/v3/ui/demo.tsx`）

| 组件 | 用途 |
| --- | --- |
| `ChipSelect` / `useFacet` / `RangeChip` | 筛选下拉。选项取自页面数据，选择后真正过滤列表；时间范围有统一的预设 |
| `AddChip` | 表单里的「+ 服务 / 成员 / 接收方 / 条件 / 标签」：从列表中选，或输入后回车添加，添加的项可以移除 |
| `openForm` / `confirmAction` / `DemoHost` | 新建、编辑类表单弹窗，以及停用、吊销、解绑等操作前的二次确认 |
| `downloadFile` / `copyText` / `SecretBox` | 导出为真实文件下载；复制到剪贴板；令牌、地址只显示一次，可复制 |
| `openExternal` | Mock 模式下提示“接入真实连接器后会在新标签页打开 X”，不再打开虚构地址；接真实后端时才真正打开 |
| `SampleOnly` | 没有契约接口的示意内容（通知模板、值班与升级、发送记录、维护窗口）：Mock 模式下显示示意数据，接真实后端时显示“待接入” |

## 修复范围

- **控件**：153 处中 149 处已接上动作。剩下 4 处是有意保留的：当前工作区菜单项、产品名确定前禁用的 Logo 上传、扫描误报，以及一个改为静态标签的 Chip。
- **标签页**：以下标签页原来切换后内容不变，现已改好：
  - 评测：数据集、评测器、人工标注；
  - 记忆：分层，以及「待确认」过滤；
  - 通知与路由：接收人、模板、值班、发送记录；
  - 服务目录：我负责的、我关注的；
  - 静默与抑制：静默、抑制规则、维护窗口（原先完全点不动）。
- **导出**：以下几处原来只弹提示，现在会真正下载文件：
  - 护栏审计报告、运行记录（JSON）；
  - 覆盖矩阵、表格产物（CSV）；
  - 计划画布、故障报告（Markdown）；
  - 部署清单（YAML）、Push 接口 OpenAPI。
- **撤销**：执行原逻辑后，统一提示“已撤销”。
- **新建 API 令牌**：改为先填表单，创建后弹窗显示一次明文；轮换和吊销都要二次确认，吊销后该行消失。
- **提前结束静默**：调用 `DELETE /silences/{id}`，并把该行状态改为已过期。
- **拉取接入向导**：「上一步 / 下一步」可以走完全部步骤；测试一步调用 `POST /ingest/pull/{id}/test`。
- **验证中顺手修的问题**：
  - 新建事件抽屉里的 zustand 选择器每次返回新数组，直接打开 `/incidents?new=incident` 时会无限渲染、白屏；已修复。
  - 本地偏好数据损坏（例如存成 `"null"`）时，应用启动会崩溃；现在按“没有保存的偏好”处理。
