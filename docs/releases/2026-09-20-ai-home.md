# WAN-95 · AI 工作台首页与右侧汇总卡片

## 交付范围

2026-09-20 用户选定首页图并授权更新。视觉基线和确认记录在 [首页设计](../design/homepage/README.md)，对应 [WAN-95](https://linear.app/wansss/issue/WAN-95)。工作台成为一级入口，Agent 第二位且默认收起；知识库、审计和用户菜单的既有组织保留。

首页以大对话框、三项快捷入口、需要关注、待我处理、最近会话组织真实接口数据。最近会话显示两条，补充关联资源、最近进展与更新时间，取消重复环境列。三处“查看全部”均打开相应右侧卡片，支持搜索、状态和时间排序、固定、关闭；关闭不取消后台任务。

首页请求使用既有调查会话和模型接口。有多个候选目标时先补选应用环境，保留输入。创建结果不确定时不自动重建；已有会话的消息重试复用稳定请求 ID。切换全局环境后，已选应用无目标时保留选择并提示重新确认，禁止静默改投其他应用。首版不是通用任意命令执行器。

## 全局环境与兼容性

环境位于左上方，以用户有权限的现有环境 key 分组，默认全部，按用户保存选择，URL 使用 `environment_scope`。同名不同 key 的实验环境明确显示 key，不猜测合并。页面显式应用/环境筛选与旧链接优先；既有调查、审批、执行继续绑定原目标。无匹配范围不会退回查询全部。

只调整环境查看范围与导航，不改后端权限或环境 ID。后端现有批量范围最多 50 个环境，更多环境返回错误，不静默截断。本轮未增加企业级环境分类或分页协议。
