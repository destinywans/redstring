## 当前实现边界

连接器与模型由服务端配置登记，未提供完整的可视化集成管理。首条动作限单应用 Deployment Pod 模板回滚；恢复演示计数器适配仅覆盖单副本场景。更通用的动作和多副本恢复判定需后续设计。

上下文原文有体积上限，尚未加入长会话自动压缩；自然语言冲突由用户审查。知识索引使用精确余弦检索，未做容量或延迟承诺。业务仓储、向量和 Embedding 已分层，SQLite / Qdrant / Milvus / ContextDB 适配未实现。

云模型提供者尚无真实凭据验收；新增 Prometheus / Loki 独立演示组件尚未部署。企业 HA、SSO、多租户、动态插件市场与桌面发行不在本轮范围。前端、干净安装复现及完整 MVP 发布尚未完成。
