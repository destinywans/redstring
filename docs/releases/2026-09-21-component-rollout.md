- 共享分页统一右下排列：共 N 条 → 上一页 → 数字页码 / 省略号 → 下一页 → `[10 条/页]` → `前往 [P] 页`。当前页高亮；首尾箭头、空结果、加载状态及输入越界受控。未知总数的游标读取不虚构全量页码。
- 删除应用专用每页控件槽和重复样式；既有共享分页调用方同步采用同一结构。审计分页仍按用户要求保留。
- 原 `FilterSelect`、`SelectField` 通过兼容层使用样板的 Radix/cmdk 选择器：普通空筛选显示字段名，无额外“全部”选项，多选草稿需应用，菜单按内容限制宽度，同组只开一项。表单仍保留真实原生 select 的值、事件、校验与重置行为。
- 普通搜索移除额外提交按钮；原本地即时筛选保持即时，原后端提交查询通过 Enter 提交，特殊业务可显式保留提交按钮。没有更改业务查询/API 语义。
