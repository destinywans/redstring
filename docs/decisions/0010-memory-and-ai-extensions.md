# 记忆可视化与 AI 扩展

状态：用户确认查看记忆、MCP 客户端优先；受控维护方式为本轮实施建议。日期：2026-09-20。

用户希望直接看见平台管理的记忆，而非仅在对话中相信模型记住了什么；另提出 MCP、Skills 与 Prompt 示例。新增需求记录为 Linear WAN-93/94，保留原“尽快形成可展示作品”的范围取舍。

- 会话上下文仍由产品 PG 历史与不可变版本持有。模型切换不更换历史存储。界面展示分支、模型、来源与各轮快照，禁止直接改写旧版本。
- 长期知识及调查经验复用已有知识领域。修订创建草稿版本，审阅发布后参与召回；归档停止新召回，已形成的证据与旧版本保留。维护遵守既有应用操作权限，共享知识由管理员维护，不额外放宽权限。
- 知识原文和索引分离。索引模型、代次、状态可见；召回引用展示真实已提交的检索快照，不能推测模型采纳或伪造指标。
- MCP 使用官方 Go SDK 的客户端与 Streamable HTTP。显式登记只读工具和应用固定参数；不开放任意命令执行，不把服务器的 readOnlyHint 当作权限授予。凭据不会进入前端或构建输入。
- Skill 为版本化运维步骤与工具要求，Prompt 为可复用任务输入。用户选择后组合成含出处的草稿，确认发送后随会话保存；不自动升级为系统指令，不执行上传脚本。

没有引入第二套长期记忆数据库、独立 Agent Harness、插件市场或对外 MCP Server。MCP 客户端优先由用户在异步问题中明确确认。
