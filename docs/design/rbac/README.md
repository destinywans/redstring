# RBAC 关联管理视觉基线

2026-09-21，用户明确批准实施以下两张修订图。需求与决定维护在 [WAN-105](https://linear.app/wansss/issue/WAN-105)。数值仅为图稿示意，页面读取 PostgreSQL 实际记录，不按图稿数量造记录。

- [角色的权限、用户与部门关联](role-associations.png)：宽幅单层浮窗，独立页签、搜索、列表筛选、表头当前页选择，跨页草稿与新增/移除计数；底部按钮采用更明确的“保存全部关联”。
- [权限的资源关联](permission-resources.png)：同样宽幅浮窗，持续显示权限与动作，资源辨识信息、分页与跨页选择。已存在权限点击“保存资源关联”直接提交。

普通详情卡仅显示关联摘要与管理入口；宽面板浮在整个页面之上，不改变底层列表宽度。列表和操作栏分开滚动，键盘可关闭但未保存草稿应提示。保留全站字体规范的 400/500/600 字重与现有紫色强调、细线图标。

用户同期补充分页要求：每页条数数值居中，当前页可输入并直接跳转。该共用组件变化记录在 WAN-96；审计分页仍排除。
