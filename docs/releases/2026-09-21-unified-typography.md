# WAN-96 · 全平台字体统一

2026-09-21，用户要求整个 SaaS 的字体形状、粗细、大小和文字颜色统一，偏好圆润、现代、不过细的字体。此切片延续 WAN-96，替代此前系统字体和部分页面 12px 辅助文字的基线；不改变业务范围或恢复 CI/CD。

## 结果

- 按用户最新建议固定 Linear 产品界面为主要参照，实际查看官方设置页和成员列表图片；参考链接及中文适配边界写入字体规范。保留已认可的 MiSans，不把参考当作新增业务或重新设计入口的授权。
- 使用自托管 MiSans 可变字体，中文、英文、数字共用同一字体家族。正文 15px、控件与导航 14px、辅助文字 13px；标题、关键数值、首页大输入区按角色分级。常规 / 强调 / 标题字重统一为 400 / 500 / 600。
- 共享样式及已接入业务模块的字体声明改为引用同一套 token，覆盖首页、资源、基础设施、观测、告警、Agent、Runbook、集成、审计、设置、弹层与画布。代码和日志仍使用可读的等宽字体。
- 统一主文字与辅助文字颜色；深浅主题分别配置，保留告警和成功等状态语义。同级导航链接与按钮明确使用相同字重，应用标识不再混用等宽字体。
- 画布标题和视图标签按内容高度排列，修正标题换行后压住标签的情况；曲线坐标字号提高后同步留出刻度宽度。
- 同轮收回初版过度加粗：普通内容由 450 调为 400，清理下拉继承按钮、输入继承标签和普通名称被标成强调的情况。平台编辑简介、时区选项和普通列表名称不加粗；按钮/选中状态为 500，标题为 600。
- 用户同轮追加的平台概览反馈已修正：基本信息与集成概览取消左对齐限宽，铺满设置内容区并保持左右等距。工作空间名称、所有者及四类集成名称均使用 400 常规字重，分区标题继续使用 600。独立设置导航 14px、表头 14px，基础设施主要资源名称 15px。
- 字体随构建生成内容哈希资源，页面预加载并复用现有一年不可变缓存；帮助弹窗提供 MiSans 署名与完整官方许可。完整字库约 11.38 MiB，首次下载有体积成本，后续缓存复用。许可与来源见 `web/public/fonts/README.md`。

字体规范见 [typography.md](../design/typography.md)。字体统一指相同语义使用同一规则，不将标题、正文、辅助说明强行设为同一字号。

## 本轮证据

- `pnpm --dir web build` 通过，包括 TypeScript 与 Vite 构建。没有后端、数据库迁移或业务 API 改动。独立只读审查发现的资源名称偏小、独立设置表头偏小两项已修正。
- 本机 18081 已使用新静态资源，图库临时副本已恢复。已核对字体资源 HTTP 200、`font/woff2` 及一年 immutable 缓存；字体原始来源、Unicode 映射、字形与可变轴核对记录保存在字体 README。
- 实际浏览器代表性检查覆盖应用列表 / 筛选 / 详情卡片、首页大输入框、独立设置概览和成员列表、基础设施总览、记忆页、模型服务、帮助弹窗、画布预览；设置和成员页检查深色主题。桌面 1280×720 与较窄 898×998 视口分别保留证据，不代表每页在两个尺寸都检查过。
- 应用页在 1280px 下没有整页横向溢出；898px 下检查的页面保持整页宽度，密集表格保留内部滚动。画布预览的标题底部与标签顶部衔接，不再互相覆盖；预览曲线只证明排版，不证明真实模型或遥测接入。
- 平台概览最终在 898px 视口测得两张卡片左右留白均为 24px；标签和用户指明的资料 / 集成名称计算字重均为 400、字号 15px。移除卡片的 1180px 固定上限，宽窗口也随设置内容区展开。
- 最终平台编辑卡片的标签、工作空间输入、简介、时区按钮及展开选项计算字重均为 400；卡片标题为 600。取消编辑未保存，没有写入平台资料。
- 私有截图及构建日志存于 `.local/typography-review/`，不提交到源码。详细视觉检查见仓库 `design-qa.md`。

未运行全仓测试、真实模型调用、集群操作或业务写入；没有全面复测所有路由、卡片状态、手机断点及跨浏览器表现。用户产品体验仍待确认，Linear 保持 In Review。
