# 私有通用画布模板保留项

`POST /canvas-templates` 只接受本人在所选单环境中的持久通用画布。保存事务锁定当前会话、授权来源和源画布，复核 `canvas.change`、源画布引用应用的有效映射和权限；模板仍属于本人及原环境。保留步骤、内容或 Runbook 的模板记录源应用 ID，新建画布时再次复核原应用的有效映射及 `canvas.change` 权限，并检查新画布所选应用的有效映射；撤销原应用权限后不能借空 `services` 复用原内容。新画布始终从 `draft` 开始。

| `keep` 选项 | 持久来源与恢复 |
| --- | --- |
| `nodes` | 复制经验证的节点布局和有向边；不复制原节点 ID、状态徽标或实时连线。为 `false` 时丢弃布局/边，仍可把选择保留的步骤和文字放在无关联的节点中。 |
| `steps` | 只取节点中持久的 `steps` 块及描述。保存和恢复均把历史 `done` 重置为 `todo`，并标注“未执行，待复核”；审批门 `gate` 保持待批准含义。不会运行步骤。 |
| `content` | 明确选择时，仅在私人模板中保留节点标题、说明以及经验证的文字、标签、键值、提示和行标题；不复制行状态/数值、指标柱图、徽标、产物或对话。服务名与数字**不会自动脱敏**，保存前需由用户检查。 |
| `runbooks` | 只识别源画布产物中的精确本地 `/runbooks/{id}` 链接，不从节点文字猜 ID。保存时核对已发布 Runbook、真实文档版本、同环境应用绑定及当前 `knowledge.view`；使用模板时重新核对相同版本和权限，恢复为只读链接产物。没有这种明确链接时，保存响应为 `retention.runbooks=0`、`runbook_source=no_structured_reference`，不声称已保留 Runbook。 |

通用画布目前没有独立的带版本 Runbook 关联字段，冻结示例中的 Runbook 名字只是文字。精确链接是当前可读取的显式来源；其他外部 URL 或自由文本不会转成 Runbook。关联文档失去发布、变更版本或失去应用/环境/授权后，模板使用返回受控错误，不降级为无关联画布。

模板复用不复制节点交换历史、证据、工具调用、模型结果或执行状态。私人步骤、文字和 Runbook 元数据保存在模板 JSONB 中，只有本人同环境可用；严格配置导出校验拒绝这些较丰富的私人模板进入系统模板。纯结构模板仍可按既有受审提升流程导出。私人保存与系统导入共用 500 项容量锁。冻结页面仍称“团队模板”并承诺自动脱敏，这些文案需要前端验收时对齐。
