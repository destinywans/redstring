# 资源关系知识图谱 · WAN-101

2026-09-22 用户确认实施。问题、备选方案与确认历史在 [WAN-101](https://linear.app/wansss/issue/WAN-101)。基于 `0281ff0`，分支 `codex/wan-101-resource-knowledge-graph`；依赖已推送未合并的 WAN-112，不纳入暂停中的交付中心改动。

## 页面合同

- “资源关系”使用 G6 展示分组总览与局部资源图，其他画布不迁移。PostgreSQL 继续保存资源及真实关系。
- 默认按资源来源、集群和命名空间形成带数量的虚拟分组。组间线汇总真实跨组关系；分组不是新资源，不制造依赖边。
- 进入分组读取有界资源集合，聚焦具体资源读取一层关联，支持方向、展开、收起与继续加载。中心优先保留，不把数百节点整体缩到无法阅读。
- 节点使用类型图标、名称与克制的颜色；选中和悬浮突出邻接关系。线具有方向，标签按交互显示，静态关系不播放请求流量动画。
- 局部更新保留位置与缩放，初次布局结束后静止。详情使用覆盖式卡片，不压缩画布。
- 顶部控件统一：搜索、资源/关系类型多选；缩放比例、放大缩小、适应画布、真正全屏。无默认组件品牌或散落控件。
- 搜索服务端目录，支持既有中文/英文/拼音规则，选中后定位；同名项显示类型及所属范围。
- 全局环境与 RBAC 作用于节点、边、分组数量及检索结果。默认隐藏运行实例；显式查看时可纳入 Pod/容器，事件仍是运行记录。

## 数据合同与实现边界

复用 `/resource-relations`，增加 `mode=overview|neighbors`，并保留无 mode 的旧返回方式。分组与邻居返回准确的已加载/剩余数量及分页偏移。细节在 [资源 API](../resources-api.md)。单次展示与底层预加载仍设明确上限，不能以部分结果冒充全量；本轮不引入图数据库、资源写入或全量历史同步。

## 定向验收

1. 真实资源能进入分组、聚焦、展开、收起，中心和页间选择语义正确，越权/未知环境不泄漏图内容。
2. 默认名称可读，布局无长纵列，缩放与全屏确实生效，详情前后基础画布宽度相同。
3. 前端类型与构建、图查询的纯内存边界检查、真实页面的本页交互检查；不执行全站、集群、故障或业务专项测试。
4. 仅本次文件及已有脏文档中的本次片段提交推送；本机 18081 更新后由用户体验，Linear 保持 In Review。
