# RBAC 关联管理与直接跳页

任务：WAN-105；共用分页：WAN-96。分支 `codex/wan-105-rbac-associations`，依赖已推送、未合并的 `ff81ef8`。用户确认两张宽幅设计图后授权实施，并要求真实数据库角色/权限、每页数字居中和直接跳页。

## 验收范围

- 设置分别提供角色管理、权限管理。角色与权限、成员、部门均为多对多，成员最多属于一个部门；允许暂未分配部门。
- 普通详情卡承载资料与关联摘要；权限、用户、部门、资源关联使用覆盖整个底层页面的宽浮窗，不挤压基础布局。
- 服务端搜索、筛选、分页；表头只选择当前页；跨页增删保留稳定 ID，三页签统一提交，版本冲突不覆盖他人修改，关闭未保存内容需确认。
- 查看、修改、删除资源资料与调查、审批、执行、管理为分别声明的动作。资源目录记录的权限不隐式扩散到关联图、应用其他资源或外部基础设施。
- 原有账号及应用授权迁移兼容；多部门关系收敛前保留原实际应用访问权限。内置兼容角色受保护，自定义角色可增删改查。
- 角色及权限记录来自 PG，内置动作可用；新增业务角色默认不分配给成员或部门。既有业务示例资源继续显示示例标识，不能冒充真实生产资源。
- 通用分页右下展示总数、每页条数、可输入页码及左右翻页；每页数值按完整控件居中。记忆列表支持直接目标页查询，旧游标接口兼容。

## 范围边界

用户要求只做受影响定向验证，不运行全仓测试或故障注入。审计的特殊分页保留；CI/CD 的暂停实现与实验发布流程不纳入本分支，不构建其未提交代码。
