# V3 MCP 服务领域链路

[登记示例](v3-mcp-registration.json)只说明应用拥有的 MCP 记录形状，ID、应用、端点、固定参数和私有凭据文件引用均为占位符。使用现有登记 API 持久保存记录后，还必须显式绑定一个已登记环境；旧记录不会自动跨环境复制。当前 MCP 凭据来源是 `AIOPS_MCP_CREDENTIAL_ROOT` 下的私有普通文件，**不是**连接器的 Vault 凭据绑定。无需认证的端点可以没有凭据引用；声明了引用却无法读取私有文件时发现失败。未登记来源或未注入完整领域发现函数时明确报告未接入，不显示健康成功；页面和 API 不返回凭据或令牌。

`POST /mcp-servers/{id}/discover` 在当前环境、应用或所属团队的 `connectors.manage` 授权下读取。服务端先核对登记和环境绑定，再以有界 Streamable HTTP 会话完成 `initialize`，按服务声明的能力分别执行 `tools/list`、`resources/list`、`prompts/list`。未声明的能力记录为 `unsupported`，声明后读取失败则整次发现失败；空列表只有在实际成功读取后才是零。返回的声明和版本是未信任观察，不表示健康持续有效、工具已审核或 Agent 可调用。发现结果与确切登记版本、内容摘要和绑定实例关联为不可变快照；出站后再次核对来源和授权，再同事务记录审计。

`GET /mcp-servers` 与 `GET /mcp-servers/{id}` 从当前可见的绑定、最新有效发现快照和对应人类审核读取。工具的远端只读提示与描述仍是未信任数据；逐工具决定和启用偏好来自单独的审核表。已发现但未审核的工具对 Agent 不可用，启用偏好也不是 Agent 执行授权。资源、提示词和服务版本仅在受控发现实际取得后给出；协议未支持或尚未发现以显式状态及 `null` 表示，未知计数不写成零。连接状态只可表示上次成功发现的时间，不能冒充当前健康。现有通用会话工具审计和旧应用 MCP 调用无法准确归属 V3 MCP 登记/环境/审核快照，V3 调用次数与历史保持未知，直到受审执行器在调用前后写入脱敏、含来源身份的持久记录。

当前有 `connectors.manage` 权限的人类审核者先从 `GET /mcp-servers/{id}/review-candidate` 读取快照、摘要、逐工具哈希及修订；普通详情不泄露这些写入令牌。`POST /mcp-servers/{id}/review` 必须提交当前 `snapshot_id`、`registration_version`、`registration_hash`、`tools_hash` 与每个发现工具的 `name`、`tool_hash`、决定；`PATCH /mcp-servers/{id}/tools/{name}` 必须提交对应快照、摘要、登记版本和期望修订及显式 `enabled`。写入复用单环境、当前人类身份、Cookie 会话、应用/所属团队授权和登记/发现/工具版本核对；同事务保存审核或开关与审计。冻结前端的空审核请求及仅带 `enabled` 的开关请求缺少安全参数，必须被拒绝，待 WAN-117 或后续前端对齐后才能验收页面。

本分支只交领域逻辑、必要迁移和分域 OpenAPI。WAN-117 仍须将完整发现函数注入 V3 进程、纳入总 OpenAPI 并执行进程级 HTTP 验收。冻结前端直接对 `tools`、`resources`、`prompts` 和 `calls` 调用 `.map`，无法渲染未知或不支持时的 `null`；其工具授权文案、字段形状和乐观开关也与“人工审核偏好、不授予 Agent 执行”不符。页面还用登记 ID 而非“登记＋环境”作行键，写请求缺版本参数。接入真实接口前必须修这些页面缺口，领域路由通过不等于页面验收。定向测试只访问隔离 PostgreSQL 和本地合成 MCP 服务；未连接生产 MCP、未合并或部署。远端服务自行返回的工具、资源、提示词元数据应当按未信任内容展示；不通过这个链路执行任何工具、获取资源正文或运行提示词。
