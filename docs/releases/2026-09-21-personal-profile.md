# WAN-104 个人资料

2026-09-21，分支 `codex/wan-104-personal-profile`，基于已推送、未合并的 WAN-103 / `7db1062`。

## 内容与边界

设置新增个人资料；所有已登录角色可访问本人资料，管理员设置保留独立门禁。头像支持PNG/JPEG上传、预览、保存和移除；邮箱、手机号、部门、平台角色及实际授权应用只读。头像与手机号在013迁移持久保存于PG，手机号缺失不造值。

改密校验当前密码与12–1024字节新密码，事务保存并撤销所有本人会话；并发登录与改密锁定同一用户行，避免旧密码验证后又产生有效会话。目录来源不等于SSO，有本地哈希的导入成员可改密。接口不接收其他人的ID或权限变更字段，审计不记录图片或密码。
